面向个人中文口播的首个 Android 原生实验包。

- Android 10+，arm64-v8a；约 90 MB，包含中文/英文离线语音模型。
- 基于 Suflyor 改编，加入中文字符定位、数字读法与原文映射、中文界面和个人拍摄默认设置。
- 语音模式听不到输入时保持当前位置，不自动冒充语音跟读继续滚动。
- 四项中文定位测试通过，优化 APK 编译与签名检查通过；相同模型已在 Windows CPU 上处理官方录音样本。

尚未连接真实安卓手机：跨 App 麦克风共享、开拍/剪映/系统相机录像兼容性、发热和实际跟读准确性仍待试拍。原生界面也还在与已选原型对齐。

Preview 使用本机调试签名，供本阶段个人实验；不代表正式发布签名版。iOS 工程与云端构建在源码仓库中，本发行不宣称 iOS 真机可用。

安装包与源码中的第三方许可证已保留。完整说明见仓库 docs/06-原生实验版安装与验证.md。
