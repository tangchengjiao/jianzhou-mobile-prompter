# Android 0.1.0-preview.4 试用更新

2026-10-26。根据实际试用反馈改进悬浮窗、语音准备与稿件留存。

## 调整悬浮窗

- 未锁定时，拖底部中央移动条可上下、左右移动。
- 拖底部右侧细线手柄，分别调整宽度和高度；字号仍在 Aa 中独立调整。缩放手柄不再使用紫色三角，也不挤占主控栏。
- 每种横竖方向分别记住位置和尺寸，关闭后再开仍会恢复。
- 主控栏恢复单行。窄窗把上一句、下一句、锁定收进“更多”；正常宽度直接显示这些按钮。
- 点 Aa 默认显示底色不透明度滑条，可调到完全透明或完全不透明；点击左侧名称可切换字号、行数、底色、语速。应用设置中也有 0–100% 滑条。
- 状态区和底部短线都能拖动，安卓窗口没有只能放顶部或底部的吸附规则。
- 锁定后先点独立解锁按钮，才能移动和缩放。

## 保存自己的语料

- 首页编辑停止输入后自动保存，离开应用时也会保存；状态显示在稿件下面。
- “保存副本”保留当前修改稿，并在标题中加上时间，方便继续尝试另一版。
- “导出 TXT”打开系统文件保存界面，由本人选择本机目录或已有文件服务；默认文件名含标题与时间。
- 编辑后的原始换行、空格与 Markdown 标记单独存储，提词排版不会覆盖这份编辑文本。
- “全部稿件 → 更多 → 备份全部稿件”可导出 ZIP，每篇是可直接阅读的 Markdown 文件；也可以恢复到应用。
- “全部稿件 → 批量导出”进入选择模式，勾选要留存的稿件，或全选当前列表，点底部“导出”。只需选一次 ZIP 保存位置，每篇稿件为单独 UTF-8 TXT；原始文本保留，同名稿件分别命名。

## 与开拍同时使用麦克风

初测只开普通悬浮权限时，开拍收音后会使提词器收到静音；开启无障碍后已有改善反馈，尚未同时确认成片声音与完整跟读表现。

使用顺序：系统“无障碍”开启“见舟提词：悬浮与语音” → 回到应用选择“语音跟随” → 启动悬浮 → 手动切到开拍并录制。只开“允许显示在其他应用上层”不具备同样的收音共享条件。

新版会在缺少无障碍服务时解释并引导设置。悬浮语音固定使用 `VOICE_RECOGNITION` 音源；Android 11+ 明确设为非独占。若收不到音，语音模式停在当前位置，并提供由本人主动点击的“匀速提词 · 释放麦克风”。匀速模式不创建 AudioRecord，也不请求麦克风权限。

依据：[Android 音频输入共享](https://developer.android.com/media/platform/sharing-audio-input)、[Android 15 兼容性定义 5.4.5](https://source.android.com/docs/compatibility/15/android-15-cdd#5_4_5_concurrent_capture)。规则支持这条实现路径；具体手机和拍摄应用的实际录像仍需确认。

## 本次验证范围

98 项 JVM 测试通过，包括本次 TXT 压缩包的中文内容、换行和同名稿件保留；优化 Preview APK 构建及签名检查通过。本次新版的实际拖动手感、单行栏观感、系统保存器、持续录像和成片声音仍需在安卓手机试用。
