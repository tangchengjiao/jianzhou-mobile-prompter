# iOS Preview 6：防止跨段误跳，录制时收起工具

用户在构建 5 中反馈：跟读会直接跳到下方很多行；开始拍摄后，底部除录像键之外的工具应默认隐藏。

## 跟读位置

构建 5 在附近没有匹配结果时，会尝试整篇稿件重新定位。这有可能把识别结果中的常见词或后文相似句当成跨段证据。本次移除自动全文重定位，优先跟随当前正在读的文字。

- 候选文字需要与当前读到的位置相接，短词不能跳到远处。
- 一个识别任务可前进的范围，与这段声音已经识别出的文字量相关。
- 同一句话的重复回调、标点变化和同长度修订，不反复增加可前进距离。
- 保留当前位置附近的错字容忍、连续顺读，以及有明确证据的近处重读。
- 如果主动跳过一段，先在提词框中滚动到目标位置，再轻点文字定位；录像不用停止。

新增回归覆盖：后文整句不能跳过未读段落、重复假设不能走到下方同句、同长度识别修订不增加推进距离、正常连续顺读，以及识别任务重启后的衔接。旧的自动跨段测试改为验证“不能自动跳、手动定位后能继续”。

## 录制界面

- 刚开始录像时，底部默认只显示停止录像键，不显示设置、切镜头、模式、识别文字和计时栏，也去掉展开工具时的黑色底板。
- 轻点取景空白处可展开工具；4 秒后自动收起，再点也可主动收起。
- 停止录像后恢复完整工具，并保留构建 5 的自动有声预览和独立镜像设置。

本次编译、自动检查和手机覆盖安装的结果见 README 与 Releases；真实跟读是否仍误跳需要用原稿继续复测。
