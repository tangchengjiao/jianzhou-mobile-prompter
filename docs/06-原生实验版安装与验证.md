# 原生实验版安装与验证

版本：0.1.0 实验阶段；2026-10-26。

## Android

从本项目 Releases 下载 `JianzhouPrompter-Android-0.1.0-preview.4.apk`，在 Android 10+、arm64 手机上打开安装。Preview 使用本机调试签名，供本人覆盖升级。更新前可先在“全部稿件 → 更多”备份稿库。

当前可编译能力包括本地稿件、编辑导入、全屏阅读、匀速提词、无障碍悬浮路径、中文/英文离线语音识别及中文位置映射。原生界面正在与选定的稿件入口设计对齐，尚未完成真机视觉验收。

先打开示例稿件，修改为常用口播稿。语音悬浮需要麦克风及已连接的无障碍服务，普通悬浮权限不足以与拍摄应用共享收音。匀速模式不使用麦克风。默认只打开浮窗，拍摄应用由本人手动切换。

本次新增可拖动缩放的悬浮窗、首页 TXT 导出和“保存副本”；具体入口见[安卓试用反馈与更新](08-安卓试用反馈与更新.md)。

请按实际使用顺序测试：

1. 先在全屏练习里顺读，停顿，再重读一句。
2. 开启悬浮，切换到开拍、剪映或系统相机，先观察预览，再真正录像。
3. 检查原视频有声音、浮窗仍显示、跟读位置正确。界面显示“跟读中”本身不能证明这三项都通过。
4. 语音模式在听不到声音时应保持当前位置；需要时主动切换匀速。

## iOS

原生 SwiftUI/AVKit/Speech 工程位于 `ios/`。公开构建流程会在 macOS 上进行真实 Xcode 编译和定位单元测试，成功后保存未签名 IPA 与日志。

构建 3 已通过 iLoader 与本机客户端信息适配，在 iPhone 13 / iOS 27.0.1 上签名安装并打开。未签名 IPA 的下载入口见 README，更新仍需同一 Apple 账号自用签名；具体成功方法、-80046 / -23782 的区别见 [iPhone 自用安装](07-iPhone自用安装.md)。

构建 5 已继续用现有会话覆盖升级，手机安装列表已确认版本。新增按视觉行跟读、识别恢复、实时听到的文字、录后自动预览，以及独立的前置取景和成片镜像；真实识别手感与回放仍需本人复测。

全屏语音练习使用系统中文端侧识别；系统画中画使用不占麦克风的匀速模式，不能自由停在中央或调整成透明视频窗。用户已同意新增 App 内拍摄跟读：同一路声音分流到录像和识别，文字可移动、缩放和调底色。新拍摄路径的成片与声音另做真机验收。
