# 原生实验版安装与验证

版本：0.1.0 实验阶段；2026-10-26。

## Android

从本项目 Releases 下载 `JianzhouPrompter-Android-0.1.0-preview.apk`，在 Android 10+、arm64 手机上打开安装。Preview 使用本机调试签名，仅供本阶段个人实验，不是正式发布签名。

当前可编译能力包括本地稿件、编辑导入、全屏阅读、匀速提词、无障碍悬浮路径、中文/英文离线语音识别及中文位置映射。原生界面正在与选定的稿件入口设计对齐，尚未完成真机视觉验收。

先打开示例稿件，修改为常用口播稿。语音模式需要麦克风；跨应用显示还要按界面说明开启悬浮或无障碍服务。默认只打开浮窗，拍摄应用由本人手动切换，不会默认跳到 Instagram。

请按实际使用顺序测试：

1. 先在全屏练习里顺读，停顿，再重读一句。
2. 开启悬浮，切换到开拍、剪映或系统相机，先观察预览，再真正录像。
3. 检查原视频有声音、浮窗仍显示、跟读位置正确。界面显示“跟读中”本身不能证明这三项都通过。
4. 语音模式在听不到声音时应保持当前位置；需要时主动切换匀速。

## iOS

原生 SwiftUI/AVKit/Speech 工程位于 `ios/`。公开构建流程会在 macOS 上进行真实 Xcode 编译和定位单元测试，成功后保存未签名 IPA 与日志。

未签名 IPA 仍需本人自用签名才能安装，不能当作商店应用直接打开。没有 Mac 时可继续研究 Windows + AltStore；免费签名通常需要周期刷新，具体步骤在构建成功后补齐。

本阶段全屏语音练习使用支持的系统中文端侧识别；画中画先使用不占用麦克风的匀速模式。是否能配合某个拍摄应用持续录像，仍需在具体 iPhone 上测试。
